# The coursework session — the contract `learn` and `correct-exercise` share

> **Not a skill.** It has no directory and no `SKILL.md`, so it costs no description and fires on
> nothing. **It is loaded by whichever of the two doors the operator opened**, and it is the
> declared source for everything they have in common (`MLabs:AX-20`).
>
> **The two doors:** `learn` works forward from a **problem statement**; `correct-exercise` reads
> backward from **work already written**. ⛔ **Verification never shares a role with generation**, so
> a correction opens its own conversation with the artefact as its only input (`MLabs:AX-13`) —
> which is why these are two doors and not two modes of one.

## The session is ephemeral

**No persistent state, no project layer**: no compass, no plan, no decision log. Coursework is not a
project (`NEXUS:AX-2`). **Nothing survives but the deliverable and what leaves through the mailbox.**

⚠️ **This session feeds the knowledge base and never writes to it.** One named door creates and
edits notes (`NEXUS:AX-4`), and neither of these is it. **A note that arrives any other way is
indistinguishable from real knowledge to every later sweep.**

## Reads, in this order

1. **The instance binding** — it pins the rule set in force and supplies every path below. Nothing
   here is guessed from file type or location (`NEXUS:AX-3`).
2. **The flat inventory of the knowledge base**, always — so the work can cite and route **without
   loading an index or any note body** (`MLabs:AX-21`).
3. **The material the operator supplied**, exactly as supplied, with nothing normalised on the way in.
4. **One domain's notes, on demand only**, and only once the source gate puts them in scope.
   Anything opened outside the row the index pointed at is declared, and the gap is logged as a
   repair to the index (`MLabs:AX-21`).

## The source gate — run before anything is solved or judged

Recorded at the head of the output, and **combinable**:

| | |
|---|---|
| **A** | the statement and syllabus only — exam conditions |
| **B** | **+ the knowledge base** — the operator's own notes, one domain at a time |
| **C** | **+ external sources** — best available, each marked as outside the syllabus |

⛔ **The gate is not a formality: it fixes what the answer rests on, and therefore what counts as a
gap.** A judgement resting on an unstated standard is an opinion (`MLabs:AX-6`).

## Citation

**To the exact location, or the claim is marked unsourced** (`MLabs:AX-6`) — the syllabus as
`[document · module or section · page]` · the knowledge base as `[[note#section]]` · external with
its full reference and the outside-the-syllabus mark · submitted work by file, cell or line.

**A missing detail is requested from the operator and pasted in**, never reconstructed from memory,
and one missing detail never blocks the rest.

## Every gap becomes a signal

**One mailbox line each, written at the moment it is crossed**, in this shape:

```
what came up + the case that evidences it → the note that should have held it, or *does not exist*
→ the suggested action (clarify · correct · extend · create)
```

⛔ **One line, unfixed and uninvestigated** (`MLabs:AX-25`). The work does not stop for it, nothing
is repaired in passing, and **the operator triages it, never this session** (`MLabs:AX-15`).

## Verification, stated as a prediction

**The output is handed over with the prediction of what a correct run produces, before the operator
runs anything.** The operator runs it and returns the real output, and **the gap between the
prediction and that output is the finding** (`MLabs:AX-14`). Each door states its own predicate.

**What cannot be stated as a falsifiable prediction is said so rather than shipped silently**
(`MLabs:AX-6`).

## Hand back

**The deliverable, the mailbox lines, and every open thread with its destination** — each read back
from disk before it is called written (`MLabs:AX-9`).

## What neither door does

- **Create or edit a note in the knowledge base** — one named door, and neither of these is it
  (`NEXUS:AX-4`).
- **Investigate or fix a gap it finds**, however small (`MLabs:AX-25`).
- **Drain or triage the mailbox it fills** (`MLabs:AX-15`).
- **Offer divergent proposals.** This is precision work, and they are silenced in it
  (`NEXUS:AX-13`).
- **Carry project state** (`NEXUS:AX-2`).
