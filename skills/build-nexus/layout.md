# layout — the default tree, as data

> **Read by `build-nexus` layer 1, and by nothing else.** This is the **only file in the public set
> permitted to name a directory below an instance root**, and it names them **three times in total** —
> once per root — so the gate prints three lines rather than one for every path.
>
> ⚠️ **The exemption is concentrated here on purpose.** The same knowledge is currently scattered as
> prose across several skills, and `tools/install-skills.sh` already carries two `gate:allow` lines
> for exactly this reason. **One file declaring the default layout is auditable; the same fact in
> six files is not** — and an exemption you can list is a debt, while one you cannot see is a hole.
>
> ⚠️ **It is a DEFAULT, not a truth.** An instance that has moved its folders says so in its binding,
> and `build-nexus` layer 3 reads the binding. This is what a machine with **no** binding starts
> from, and nothing else may read it to find out where anything is.

## The three roots, named once

⚠️ **The roots are declared here and nowhere else in the tree below**, which is why this file carries
**three** exempted lines instead of twenty-two. The first draft spelled the root on every row; the
gate printed all of them, and **an exemption list too long to read is the same failure as an
exemption you cannot see.** Parameterising it was not a tidy-up — it made the root what it should
always have been: **a value, not a spelling.**

```
SYS   = 99_SYSTEM     # gate:allow the builder declares the default roots, and only here
PROJ  = 98_PROJECTS   # gate:allow same
DOM   = 01_ .. 08_    # gate:allow same — the knowledge domains, and they are optional
```

## The tree

Each line names a path **under a root above** and the **kind** (`METHOD.md` §1) of what is created
there. The kind is the contract; the filename is a convention this file happens to declare.

```
# ── the operations centre ────────────────────────────────────────────────────
$SYS/PURPOSE.md            Standing   what this instance is for — left for its owner
$SYS/AXIOMS.md             Standing   the instance's own axiom department
$SYS/AGENTS.md             Standing   the binding — the one file naming MLabs
$SYS/COMPASS.md            Compass    one ▶, seeded with *set your first front*
$SYS/PLAN.md               Live plan  the active plan, or the id of it
$SYS/MAILBOX.md            Queue      agent → operator, and the only human entry point
$SYS/TASKS.md              Queue      produced by triage, never typed
$SYS/FAST-TASKS.md         Queue      C0 work — hands, not judgement
$SYS/IDEAS.md              Park       undecided, one line while fresh
$SYS/LOG_METHOD.md         Record     decisions about the method
$SYS/LOG_AGENTS.md         Record     what each agent did, per round
$SYS/LOG_WORK.md           Record     what the operator delivered
$SYS/LOG_EXTERNAL.md       Record     defects found in code the operator does not own
$SYS/logs/README.md        Standing   the employee-log contract and the weights
$SYS/logs/                 —          one Record per role, created when the role is
$SYS/data/SCHEMA.md        Standing   the field contract for the record store
$SYS/data/FLOW.md          Standing   block → sub-block → plan → item
$SYS/scripts/metrics.py    —          the numbers, computed and never transcribed
$SYS/scripts/coherence.py  —          the vault check. Ships exiting 2 — see below
$SYS/denylist.txt          Standing   HARD · SOFT · SIGNATURE. Created EMPTY
$SYS/interface.json        —          the adapter, generated by layer 3
# ── projects ─────────────────────────────────────────────────────────────────
$PROJ/                    —          one folder per project, opened by structure-project
# ── knowledge, and it is optional ────────────────────────────────────────────
# Created only if layer 2 finds notes, or the owner asks. An instance that is all
# projects and no vault is a legitimate instance, and eight empty folders would be
# the accumulation the philosophy refuses.
$DOM/                       —          knowledge domains, numbered, each with an index
```

## Three files whose creation is a decision, not a default

- **`denylist.txt` is created EMPTY, and the gate refuses to pass on an empty denylist.** That is
  correct and deliberate: **a list of the owner's own private names cannot be guessed**, and a
  builder that seeded it with plausible entries would produce a gate that looks armed and is not.
  ⚠️ The first release cut fails until the owner fills it. **That failure is the feature.**

- **`coherence.py` ships exiting `2` — *could not run, which is NOT a pass*** — the contract
  `tools/gate.sh` states in its own header. With no domains configured it must not return 0.
  ⚠️ **Two instance invariants name this file**, and a generated checker returning 0 over zero files
  would make both pass vacuously — the exact defect class the builder exists to close, committed by
  the builder.

- **`AGENTS.md` is the binding and is the ONE file that names MLabs.** Everything else reaches the
  method through it. ⚠️ **It is generated, never hand-written** (`AX-30`) — and the authoring
  repository's own contract is currently hand-written and declares that debt, so this is the first
  place the axiom is actually obeyed.

## What is deliberately absent

**No `Schedule.md`, no `Current_plan.md`, no `TASKS_agents.md`, no `MAILBOX_agents.md`, no
`instructions/`, no `workflow.md`, no `00_ROUTER.md` at the instance root.** Every one of those
belonged to a structure dissolved on 2026-08-17, and several are still named by a skill that was
never updated. **A builder is where a dead layout would be resurrected without anyone deciding to**,
so the absence is written down rather than left to be noticed.
